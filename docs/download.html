Install notes

sqlr is a portable app: no service, no background daemon, no runtime to install.

Install from the terminal (Linux and macOS)

Downloads the latest release for your system and architecture, verifies its checksum and installs it:

curl -fsSL https://raw.githubusercontent.com/mceck/sqlr/main/scripts/get-sqlr.sh | sh

Linux goes to ~/.local (SQLR_PREFIX changes it), macOS to /Applications. SQLR_VERSION=0.2.0 picks a specific version.

macOS

Open the .dmg and drag sqlr onto Applications.

Releases are ad-hoc signed, not notarized. On first launch, right-click sqlr and choose Open, or run:

xattr -dr com.apple.quarantine /Applications/sqlr.app

Windows

Unzip the download and run sqlr.exe. There is no installer and no runtime dependency.

The executable is unsigned, so SmartScreen may ask for confirmation the first time: choose More info, then Run anyway.

Linux

AppImage:

chmod +x sqlr_*.AppImage && ./sqlr_*.AppImage

Tarball:

tar -xzf sqlr_*_linux-*.tar.gz
sudo cp -r sqlr_*/bin sqlr_*/share /usr/local/

Built on Ubuntu 22.04 for an older glibc.
