Understand sqlr's terms

Use this glossary when a label in sqlr or a procedure in the manual is unfamiliar.

Connections and access

TermMeaning
ConnectionSaved settings for reaching a database server or file. Passwords are stored separately
FolderA group of saved connections in the explorer
Connection URLAn address you can paste to fill a connection form
Connection profileA named set of commit rules, protections and color, such as Development or Production
SessionA live database connection, with its own transaction state
Editor sessionThe session used by one editor tab when separate sessions are enabled
Server sessionA database server's view of an active connection, shown in administration
Credential vaultThe encrypted file holding saved passwords, SSH secrets and the MCP token; the OS keychain protects its key
Demo databaseThe sample SQLite database available from the welcome screen

Browse, query and edit

TermMeaning
ExplorerThe tree of connections, databases, schemas and objects on the left
CatalogInformation about database objects, used by browsing, autocomplete and object search
Catalog cacheA saved copy of that information, which may need refreshing after server changes
Editor tabA query editor associated with a connection and, when applicable, a database
PaletteKeyboard search for objects or commands
Result gridThe table displaying returned rows
Page sizeThe number of rows requested with each fetch
Value panelThe panel showing the selected cell, document or key value in full
ChangesetYour unapplied cell edits, inserted rows and deleted rows
Row keyThe primary key or non-null unique key identifying a row for editing
Object editorA tab for inspecting and changing an object's structure
Schema change listStructural edits waiting for you to apply their generated DDL
DDLSQL that defines or changes database objects, such as CREATE TABLE
DDL viewerA read-only tab showing an object's definition
Commit modeAuto, Manual or Smart rules for starting and committing transactions
Destructive statementA statement that can remove data in bulk, such as DROP, TRUNCATE or a DELETE without WHERE
Key browserThe Redis view of keys grouped by prefix and value type
Copy formatThe text representation of copied cells: for example TSV, JSON or SQL INSERT
Typed clipboardValues sqlr keeps alongside copied text to preserve their types when pasted within the app
HistoryThe searchable record of executed statements and their outcomes
SnippetA saved query, available globally or for one connection

Tools and drivers

TermMeaning
OperationA piece of work currently running or recently finished in sqlr
JobA background operation with progress, such as importing rows or applying edits
Operations panelThe list where you inspect progress and cancel work
Data transferMoving data between a source and a destination, including import and export
EndpointA transfer's source or destination, such as a query, table or file
Dump / RestoreBacking up or restoring a database with its native tools
Saved taskA named transfer, dump, restore or script you can run again
Task runOne saved task's execution and recorded outcome
Schema compareA comparison of structures with a generated migration script
ER diagramA drawing of tables and their foreign-key relationships
Explain planA database's description of how it will execute a statement
DriverThe component that lets sqlr communicate with a database
CapabilityAn optional feature a driver supports; unavailable features are hidden or disabled
Bundled driverA driver included in the application
Sidecar driverA driver running in a separate process
Driver archiveAn installable sidecar driver package for your platform
Active versionThe installed driver version used by new sessions
JDBC bridgeA sidecar driver that uses Java and a JDBC driver to reach a database

Settings, agents and reports

TermMeaning
Setting levelGlobal, connection profile or connection scope for a preference
Safety flagA protection that a more specific setting can enable but cannot weaken
KeymapThe commands and keyboard shortcuts selected by your preset and customizations
MCP serversqlr's local interface for agent tools, available while the application runs
Agent accessA connection's None, Read or Write permission for agents
Agent sessionAn agent's separate database session, isolated from your editors
MCP tokenThe credential an MCP client must send to use the server
Discovery fileThe token-free mcp.json describing the running MCP endpoint
ApprovalThe dialog where you allow or deny an agent's protected request
IncidentA local record of an unexpected application failure
Diagnostics bundleA bounded report you can review, copy, save or share
App sessionOne run of sqlr, from launch to exit
Startup noticeA banner reporting an earlier panic or unclean shutdown
